Wikihub Studios — Selected Work galleries

Each Selected Work card (Weddings, Portraits, Events, Graduation) is a compact gallery. One cover image is visible at a time. The cover subtly teases the next frame while idle, then returns without advancing. Visitors can browse manually using the left/right arrows, swipe horizontally on touchscreens, or use the keyboard arrow keys when focused. Each gallery is independent and does not auto-advance.

Replace the sample image URLs in index.html with the real project images when ready. Keep index.html, style.css and script.js together.
